# Create Video

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Programa para criação de vídeos a partir de imagens estáticas. No exemplo dado, é criado um vídeo sobre o pôr do sol.

---
## 📚 Aprendizados
- Criação de vídeos a partir de imagens estáticas por meio do Python
- Aplicação de recurso do módulo OS

## ⚙️ Funcionalidades
- Ao executar o arquivo no VSCode será criado um arquivo de vídeo com o vídeo do pôr do sol

## 🛠️ Stack
Informe as tecnologias, bibliotecas e frameworks utilizados. Exemplos:

- Python
- OS
- OpenCV

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO
```

2. Abra o arquivo `index.html` em seu navegador.
